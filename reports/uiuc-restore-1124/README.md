# UIUC native package restoration

A direct native rebuild ignored reviewed `year_proofs` and depended on an absent generated yearly-listing cache. The recovery inputs had already landed; landing the old branches again would not fix the loss. Native PI assembly now reads reviewed year proofs directly and applies the existing name, date, faculty-role and departure gates.

The previous 4,852-paper candidate lost 257 listing years across 30 PIs. Existing reviewed proofs cover 170 of these years; 87 source-verified proofs are added for the other years. Original response bytes and verbatim quotes for all 257 years were rechecked and retained under the UIUC metadata store. The source receipt records their hashes and paths.

Promotion requires retention of every association from both the previous full package and the current student-bearing package, every existing student record, and all prior supported listing years. The native candidate is built privately from committed code and reviewed inputs.


The complete offline lab-page audit covered all 370 PIs and proposed 948 members. Round 1 failed on foreign/pre-UIUC/shared-roster membership and affiliation labels; round 2 failed on collaborator/high-school and degree-history/section parsing. Both failed candidates and all three seeded verdict sets are retained here. The final source-supported subset contains 399 proposed members; 549 uncertain entries remain recorded as per-person holds, not absence findings. Round 3 (seed 112403) passed the existing bar: zero membership errors/doubts and one conservative missing-degree role among 20 source-hash-verified items. No global extractor rule changed. Lab-page papers are not accepted. The student subset must still pass a private native build and preservation check before canonical promotion.

The original full UIUC package already carried one `reviewed_publisher_marker` value for the independently checked CREATOR publisher byline. The paper schema now recognizes that existing value while retaining strict quote/hash and unknown-value checks.
