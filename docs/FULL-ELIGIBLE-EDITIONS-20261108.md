# Complete eligible edition records before selecting a lead

An OpenAlex record encountered first for a collection work could retain the lead even when a later, independently eligible record described its published version. `rows_from_hits` had already reduced that later record to a compact pointer; `recovered_rows` discarded an independently eligible recovery of an already-seen collection work. The ordinary publisher preference and exact reviewed target selector consequently never saw its full authorship, appointment, date and type.

The native pipeline now retains complete raw and recovered records through the normal identity, own-school, appointment and paper-type checks. Newly retained recoveries of existing works require an explicit PI byline; their OpenAlex school claim is replayed against the original work even for legacy charters. Explicit recovered source types are preserved and checked against the existing non-paper type exclusions. A recovery cannot become a publisher merely because a manuscript already exists.

Before book folding, `collapse_eligible_sources` retains the first normally eligible representative of each established exact PI/collection work (or PI/source identity). This representative fixes the ordinary R16 identity key and counts one scientific chapter. Its complete eligible alternatives survive internally. Metadata preference runs only after those existing collection/R16 components are fixed, so selecting a publisher with a different title cannot merge an unrelated component. Six source versions of one chapter count once; five distinct chapters still invoke the existing book rule. Exact reviewed targets can select only a full record that independently passed the ordinary gates. Compact pointers never reconstruct or admit a missing publisher.

The new exact PI/OpenAlex bridge applies only between different established components. A compatible ordered byline plus a common DOI, or one missing DOI, may join those components. Different populated DOI families, unresolved bylines, or no DOI support leave them separate with explicit diagnostics. Before joining anything, missing-DOI components with incompatible identified neighbors withhold every such edge; input order cannot choose a publication on their behalf. No fuzzy-title or name-only join is added.

Discrepancies inside an already established collection/R16 component are retained as source diagnostics, rather than treating every inherited source grouping as a newly asserted scientific identity. Complete source bylines, school flags, dates, types and appointment evidence remain available until selection; the chosen metadata comes from one complete record. Compact edition identifiers use the existing package schema; every eligible source's byline remains available through the existing candidate-link routes. Internal full-record fields do not enter packages. The existing R15 translation gate is applied per source before grouping; a translated alternate cannot lead or lend student bylines. Exact reviewed source holds are applied to recoveries before folding, so a held alias cannot poison an eligible source sharing its collection identity. This does not certify conflicting source metadata or verify a person from a matching byline.

## Source-real translation-gate correction

The first component-corrected cold trial32149453 revealed an existing R15 language heuristic false positive: “How Much Do Women Build Open Source Infrastructure?” (W4402666620, DOI10.1007/978-1-4842-9651-6_14) is an English book chapter. Its word “do” matched Portuguese, while “how” was absent from the English function-word cues. The raw publisher records for both Laura Dabbish and Bogdan Vasilescu were filtered, although their full R36 article-typed counterparts remained normally eligible. The first trial, its101/103 exact-source finding and every original source byte remain preserved.

English interrogatives now count as English function-word evidence. No school, DOI or exact-title exception is used; the Portuguese word “do” remains a foreign cue in titles without English function-word evidence. Both actual PI/publisher projections, generic English questions and Portuguese/German/French negative controls are tested. This changes only the translation classification; ordinary identity, own-school, appointment and type checks remain mandatory. The original raw records and their source hashes are unchanged.
