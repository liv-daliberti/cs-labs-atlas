# AI dose: how the amount of AI in a paper relates to its novelty and diversity (owner 2026-11-04)

Report: `ai-writing/diversity/reports/AI-DOSE-NOVELTY-DIVERSITY.md` (generated by `dose_report.py`). Site data: `ai-writing/diversity/site-data/` (`dose_site.py`).

## The score container: `ai-writing/data/ai-scores/ai_scores.sqlite` (slot `AI_SCORES`, git-ignored; `papers.parquet` is a copy of the papers table)
| table | content |
|---|---|
| `papers` | one row per universe paper (`paper_id` = atlas id `atl:w:...`, the key of `embeddings/universe.sqlite`): `home_school`, `year`, `p_ai_abstract` (v1 detector on `title \| abstract`, flag `flag_abstract` at its 1% threshold), `p_v2_abstract` (v2 model on the abstract alone: NOT calibrated for abstracts, 11-16% of 2016-2021 abstracts flag; robustness only), `ai_share` (flagged passages / passages, the dose), `mean_p_par`, `ai_any`, `n_passages`, `n_flagged`, `body_words`, `text_kind`, `kobak_abs`, `kobak_ft` (Kobak et al. style words per 1,000 tokens), `ai_share_cal` (dose at a school/field-recalibrated threshold, only where `dose_validate.py --recalibrate` found a group above 1.5%), hashes, `detector_version`, thresholds |
| `passages` | `paper_id, pidx, words, p`: every scored passage, so thresholds can be re-cut |
| `thresholds` | the thresholds in use (abstract v1 1.246e-6, paragraph v2 8.53e-4, plus group cuts) |
| `meta` | build time, counts |
Scores are of the texts in `embeddings/texts.sqlite` (full text = `usable` bodies; passages as `diversity/common.passages`, normalizer `detector_v2/v2common.norm`). Precision: bf16 on RTX A5000, as both detectors were calibrated; the 2080 Ti lanes (fp16) are used only after `check_precision.py` passes.

## Pipeline
`dose_score.py` (GPU, `dose_score.slurm`) -> `dose_build.py` -> `dose_validate.py [--recalibrate]` -> `dose_mech.py embed` + `dose_mechanical.py measure` -> `dose_analysis.py paper` -> `dose_lab.py panel/did` -> `dose_site.py` -> `dose_report.py`. CPU steps run through `dose_cpu.slurm <script> args`. Detector-free: `dose_excess_run.py kobak|liang`. Extra OpenAlex fields (reference lists, OA status, venue type, author ids): `oa_extra.py` (rerun after the universe changes).
