# ai-writing/data/sections/sections.sqlite (git-ignored; built 2026-11-05 by run_split.py + merge_sections.py)
- `sections(paper_id PK, key, school, path, kind, main zlib, appendix zlib, flags JSON, main_words, appendix_words, references_chars, appendix_found, appendix_position, appendix_rule, truncated, copy_missing, split_error, n_main_passages, n_appendix_passages, n_main_identical, n_old_passages)`: `paper_id` = `ai_scores.sqlite` / `embeddings/texts.sqlite` id; `key` = fulltext.sqlite / detector_v2 key (NULL when the copy is not in fulltext.sqlite). `appendix_rule` appendix | lettered | supplementary | xml_back (supplementary counts as appendix; filter on the rule to exclude it).
- `passage_tags(src, id, pidx, section, words)`: `src='ai_scores'` joins to `ai_scores.sqlite.passages(paper_id, pidx)`; `src='detector_v2'` joins to `detector_v2/passage_scores.jsonl.gz (key, pidx)`. `section` = main | appendix | references | unknown (unknown: < half of the passage's 8-word shingles in any part). Main-body dose = flagged / total over `section='main'`.
- `passages(paper_id, i, section, text_hash, words)`: the passage lists a main / main+appendix scorer would cut (`common.passages(main)`, then of the appendix).
- `meta(verify)`: JSON of the join counts.
