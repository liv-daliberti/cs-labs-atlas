# AI added in revision (Experiment B, owner decision 2026-11-05)

Report: `ai-writing/diversity/reports/AI-IN-REVISION.md` (generated by `rv_report.py`). Container: `ai-writing/data/revision/` (git-ignored): `revision.sqlite` (matches, version listing, plan, texts), `parts/<detector>/`
(passage and abstract scores), `results/revision_<detector>_*.parquet`.

Re-run: `revision/rv_run.sh all` (stages `match`, `fetch`, `score`, `analysis`, `report`); `DETECTOR=v3 revision/rv_run.sh score` then `analysis`, `report` after detector v3 is trained.
The paper set is `RV_UNIVERSE_DB` (default `embeddings/universe.sqlite`); the final set (release 20261105i) needs `match`, `fetch`, `score` for the new papers only (fetch chunks and score parts are resumable
and skip finished texts).

Two pair kinds (the arXiv bucket does not hold late revisions of old papers, so the contrast v1-before-Dec-2022 against final-after needs a stored copy):
- **S**: arXiv v1 (public bucket copy) against the lab paper's stored full text (texts.sqlite; the dose study's own scores for v2), dated by the paper's publication date.
- **A**: arXiv v1 against the bucket's latest arXiv version (revisions within weeks), dated by the PDF margin stamp.
Never arxiv.org; bucket host `storage.googleapis.com`, see `docs/CHANNELS.md` (`arxiv_bulk`).
