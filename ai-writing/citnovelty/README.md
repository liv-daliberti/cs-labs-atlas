# Citation-based novelty and diversity (Experiment A, owner decision 2026-11-05)

Report: `ai-writing/diversity/reports/CITATION-NOVELTY.md` (generated by `cn_report.py`). Container: `ai-writing/data/citnovelty/` (git-ignored): `citnovelty.sqlite` (meta of every referenced work),
`counts.npz` (citation counts per focal paper by citing-year offset), `results/*.parquet`.

Re-run everything: `citnovelty/cn_run.sh all` (stages: `stream`, `measures`, `analysis`, `report`). Configured by paths only: `CN_UNIVERSE_DB` / `CN_OA_EXTRA` (paper set and its reference lists,
`dose/oa_extra.py`), `CN_DATA`, `CN_REPORT_DIR`. After the final paper set (release 20261105i) re-run `dose/oa_extra.py` for new works, then `cn_run.sh all`. Detector v3 only changes the AI dose column
(`AI_SCORES` rebuilt by the dose pipeline): re-run `analysis` and `report`.

| file | role |
|---|---|
| `cn_stream.py` / `.slurm` | one pass over the OpenAlex works snapshot on S3 (no API credits): meta of referenced works, exact n_i / n_j citation counts, sampled n_k |
| `cn_measures.py` | Uzzi atypicality (per-year degree-preserving null), disruption CD_w, Rao-Stirling and entropies, lab reference overlap |
| `cn_analysis.py` | coverage, trends by school, within-lab pre/post-2023 DiD with placebo breaks, paper-level dose designs (the dose report's controls) |
| `cn_report.py` | the markdown report from `results/` |
